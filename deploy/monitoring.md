# Uptime Monitoring

Health endpoint:
- `https://your-domain.com/healthz/`

## UptimeRobot sozlash
1. UptimeRobot'ga kiring va `Add New Monitor` ni tanlang.
2. Monitor type: `HTTP(s)`.
3. URL: `https://your-domain.com/healthz/`.
4. Interval: 5 daqiqa.
5. Alert contact: email yoki Telegram.

## Better Stack (alternativa)
1. New Monitor yarating.
2. Endpoint: `https://your-domain.com/healthz/`.
3. Expected status: `200`.
4. On-call/alert kanallarini ulang.
